# README — «Медиа дневник» (форк)

Автономное офлайн-приложение для журналирования любых видов медиа: игры, фильмы, сериалы,
аниме, манга, комиксы, манхва, мультфильмы, мультсериалы, книги — и свои типы.
Ветвь без рекомендаций: только ваш журнал.

## Структура
| Файл / папка | Что это |
|---|---|
| `media-diary.html` | Собранное однофайловое приложение (открывается в браузере) |
| `app/` | Исходники: shell.html + base.css + overrides.css + js-модули |
| `android/` | Gradle-проект (WebView, без INTERNET) |
| `builds/` | Готовые APK |
| `qa.html` | 35 интерфейсных тестов (итог в `#summary`) |
| `docs/` | Документация: ARCHITECTURE, DATA, BUILD, TASKS |
| `AGENTS.md` | Правила для ИИ-агентов |

## Возможности
- **Типы медиа** (настраиваются): пресеты + свои типы с выбором полей (шаблоны игр/фильмов/книг)
  и **шаблоном плитки карточки** (какие поля показывать и в каком порядке).
- **Состояния**: В планах · В процессе · Завершено · Брошено; свайп вбок между вкладками (как в Telegram).
- **Прохождения/просмотры**: журнал с датой и часами у каждого элемента; кнопка «Ещё проход»;
  сумма часов в статистике; **табличный вид** с сортировкой по дате просмотра.
- **Парсер по ссылке**: вставьте ссылку на Steam/Кинопоиск/MyAnimeList/любой сайт — название,
  год, описание и обложка подтянутся (в APK — без CORS через перехват; сеть нужна только в момент добавления).
- Своя оценка 1–10 и оценка критиков — обе на обложке; поля студии и страны (у медиа-типов).
- Заметки с шаблонами (Сессия/Первые впечатления/…), экспорт и импорт `.md`.
- Экспорт списка в `.md` и `.xlsx` (настоящий OOXML) — с датами и часами прохождений.
- Теги: свои, с цветом; единая форма; фильтр по тегам; поиск по всем полям.
- Статистика: проценты по состояниям, прохождения и часы.
- Экспорт/импорт всего состояния JSON.
